# Scripts

- `compile` -> uses required flags and -D TEST so you can test your code and it uses norminette at the end.
- `mini` -> this will save your life, run it on a C exercise folder.
- `clipboard` -> this will create a file containing the history of your clipboard.
- `vicheck` -> will format your C code
- `createdir` -> will create a directory based on the git repo you input and the exercise directories
